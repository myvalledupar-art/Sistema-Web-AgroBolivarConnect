# 🌱 AgroBolívar Connect

### Sistema Web para la Gestión y Comercialización de Productos Agrícolas del Departamento de Bolívar

---

## 📖 Descripción

**AgroBolívar Connect** Es una plataforma web desarrollada para facilitar la gestión y comercialización de productos agrícolas en el departamento de Bolívar.

La aplicación permite administrar agricultores, compradores y productos agrícolas mediante una arquitectura moderna basada en ASP.NET Core Web API, SQL Server y tecnologías web.

---

## 🎯 Objetivo

Facilitar la interacción entre agricultores y compradores mediante una plataforma tecnológica que permita gestionar información agrícola de manera eficiente y organizada.
